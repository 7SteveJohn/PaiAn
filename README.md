## 它是什么

拍案是一个给网文作者用的 **Windows 本地创作工作台**（Electron 桌面应用）。

打开即用，不联网也能写、不注册、不看广告。所有数据——作品、章节、快照、灵感、人物卡——全部存在本机文件夹里，想搬到哪就搬到哪。

适合这些场景：

- 📚 有完整大纲，想让 AI 按细纲逐章出稿，自己只做取舍和润色
- ✍️ 日更压力下，用「写本卷」批量生成整卷草稿打底，再逐章精修
- 🧠 长篇写到几十万字，怕人物设定崩、前文伏笔忘——让出场记忆替你盯着
- 💡 灵感来了随手记进灵感库，回头一键并进大纲
- 📤 写完直接导出 md / txt / 分卷 / docx / epub 去平台发布

不适合：指望一句话生成一整本拿去直接卖。AI 出的是**按你的细纲写的草稿**，成稿质量取决于你给的大纲和把关。

## 下载与安装

到 [Releases 页面](https://github.com/7SteveJohn/PaiAn/releases/latest) 下载，二选一：

| 文件 | 说明 |
| --- | --- |
| `PaiAn-Setup-1.0.2.exe` | **安装版**（推荐）：装完有开始菜单/桌面快捷方式，可自选安装目录 |
| `PaiAn-Portable-1.0.2.zip` | **免安装版**：解压即用，适合放 U 盘或不想动注册表 |

**系统要求**：Windows 10 / 11（x64）。

- 安装版与免安装版**不需要装 Node.js**，双击就能跑。
- 首次启动会自己在 `%APPDATA%\创作工作台\` 下建数据目录，卸载不会删你的稿子。

## 使用方式

1. **下载安装** → 运行 `PaiAn-Setup-1.0.2.exe`，或解压免安装包
2. **接 AI**（可选）→ 设置里选本地 Ollama（一键填好、0 成本），或粘贴任意 OpenAI 兼容 API 的 Key（DeepSeek / 智谱 / Kimi…），Key 只存本机
3. **建书导大纲** → 新建项目 → 导入大纲文件（md / txt / docx），自动识别卷标、建卷建章
4. **批量出稿** → 选中卷点「写本卷」，逐章审阅采纳，导出发布

> **注意**：AI 生成的草稿都落在「待审草稿」里，**采纳才进正文**，原正文会先存快照——AI 永远不会背着你改稿。

## 六大功能

### ✍️ 写作台 — 章级编辑与自动保存

- CodeMirror 6 编辑器：流畅长文输入，自动保存不打断打字
- 每章独立字数统计、章节历史快照（最多 20 份），写崩了随时回滚
- 大纲页直出「作品健康度」：卡文、断更、要点缺失一眼看清

### 🤖 AI 工坊 — 按细纲代笔，字数可控

- **写一段 / 本章草稿 / 写本卷 / 写全书**：从单段到整卷批量出稿，每章字数 300–5000 自定义（默认 2000，网文单章标准）
- 续写、润色、扩写、本章整理、视角实验、张力分析、简介与标题生成
- **内容门禁**：要点太薄的章会先提醒再生成，避免 AI 现编剧情掉回套路
- **提示词覆盖**：每类任务的自定义提示词，写谁像谁
- 批量进度实时显示当前章、成功/失败与缓存命中率

### 🧠 出场记忆 — 长篇不崩人设

- 采纳章节后自动抽取出场人物/物品/事件，写进人物卡与设定卡
- 人物状态与履历自动追加，幻觉角色一键清洗
- 伏笔从埋设到回收全程追踪，牵线画布可视化人物关系

### 🗂 大纲与灵感 — 书 → 卷 → 章

- **书 → 卷 → 章**三级结构：导入大纲文件（md/txt/docx）自动识别卷标、建卷建章
- 「并入大纲」按章名把大纲段落分发到对应章的剧情要点
- 灵感库随手记，标签分类 + 全文搜索，一键并入大纲或新建作品
- 场景板按空行切块重排章节结构，牵线画布梳理人物关系

### 🎲 卡池与取名 — 灵感不再枯竭

- 卡池抽卡出设定灵感，卡牌可收藏进设定
- 取名大师：中文人名/地名/功法批量生成，钉住常驻抽屉

### 🗃 数据安全 — 全本地，可迁移

- 自动保存 + **每日自动备份**（保留 7 天）+ 设置里一键从备份恢复
- **数据文件夹一键迁移**：设置里换个位置，自动搬全部数据与备份并重启
- 导出：md / txt / 分卷 / docx / epub；Obsidian 库双向同步

## AI 怎么接

三种协议、32 家厂商预设，都在「设置 → AI」里：

| 路线 | 怎么配 | 适合 |
| --- | --- | --- |
| **本地 Ollama**（推荐起步） | 装好 Ollama 并 `ollama pull qwen3:8b`，供应商选 Ollama，地址 `http://127.0.0.1:11434` | 零 API 成本、断网可用；8GB 显存可跑 8b |
| OpenAI 兼容 | 供应商选 DeepSeek / 智谱 / Kimi / 通义 / OpenAI…，填 Key 即可 | 出稿质量更稳，按量付费 |
| Anthropic 原生 | 供应商选 Claude，填 Key（走 `/v1/messages` 原生协议） | 已有 Claude 额度 |

- API Key 存在本机 `ai.json` 里，输入框是**标准密码框**：闭眼显示圆点、睁眼看明文，重启不丢。
- 可以给 AI 配「文风规则」（如"少用形容词，多用动作与对白"），启用后自动注入所有 AI 调用。
- 不接 AI 也完全能用：建卷建章、写正文、导出、统计都不受影响。

## 数据与隐私

- **数据在哪**：安装版默认 `%APPDATA%\创作工作台\data\`；源码运行版在项目 `data/`。设置里可改到任意目录（含同步盘）。
- **数据结构**：全部是明文 JSON（`projects.json` / `ideas.json` / `versions.json` …），出错时看得懂、改得动。
- **备份**：每次启动自动备份到 `data/backups/<日期>/`，保留 7 天，设置页有日期下拉一键恢复。
- **不上传**：无遥测、无账号系统、不联服务器。唯一会外发的请求，是你自己配的那个 AI 服务商。
- **可迁移**：整个数据文件夹拷走即可；也可以在设置里一键换位置，程序自动搬完并重启。

## 常见问题

<details>
<summary><b>必须接 AI 才能用吗？</b></summary>

不用。不接 AI 也能建书、导大纲、写正文、导出、看统计；AI 只负责"按细纲出草稿"这一环。
</details>

<details>
<summary><b>我的稿子会被上传吗？</b></summary>

不会。数据只写本机文件夹；只有你点 AI 动作时，相关上下文才会发给你自己配置的服务商（本地 Ollama 则完全不出本机）。
</details>

<details>
<summary><b>换电脑怎么搬？</b></summary>

把数据文件夹整个拷到新机器，在设置里指过去即可；也可以在设置里「更改位置」一键搬家。
</details>

<details>
<summary><b>卸载会删稿吗？</b></summary>

不会，卸载不动数据目录（安装包已勾选不删用户数据）。想彻底清干净，手动删 `%APPDATA%\创作工作台\`。
</details>

<details>
<summary><b>要装 Node.js 吗？</b></summary>

安装版/免安装版都不用。只有从源码跑才需要 Node 18+。
</details>

<details>
<summary><b>为什么叫「拍案」？</b></summary>

取自「拍案惊奇」——愿你写出的东西，配得上每一次拍案。
</details>

## 从源码运行

```bash
git clone https://github.com/7SteveJohn/PaiAn.git
cd PaiAn
npm install
npm start          # 浏览器打开 http://127.0.0.1:4321（需要已装 Node 18+）
npm run dev        # 前端热更新（另开一个终端跑 npm start 提供 API）
npm test           # 回归测试（node --test，无额外依赖）
npm run dist       # 打 Windows 安装版 / 便携版 / zip
```

## 技术细节

- **架构**：Electron 44 + React 18 + 本地 Node 服务，数据为本机 JSON 文件（每日备份，保留 7 天）
- **AI 协议**：OpenAI 兼容 SSE / Anthropic 原生 / Ollama 原生，32 家厂商预设，提示词流式输出
- **编辑器**：CodeMirror 6（Markdown），自定义主题，自动保存与撤销栈
- **隐私**：无遥测、无上传、无账号系统；卸载即数据仍在你的文件夹
- **开源协议**：MIT License
