# 拍案（PaiAn）— 本地网文 AI 创作工作台

> 从灵感收集到成稿发布，把整本书的写作流程装进一个桌面应用。**数据 100% 本地，AI 可走本地模型，断网也能写。**
>
> 先说清楚定位：它是**代笔助手**，按你的大纲和设定出稿，成稿的取舍权永远在作者手里——不是一键洗稿机。

## 它是什么

拍案是一个给网文作者用的 **Windows 本地创作工作台**（Electron 桌面应用）。

打开即用，不联网也能写、不注册、不看广告。所有数据——作品、章节、快照、灵感、人物卡——全部存在本机文件夹里，想搬到哪就搬到哪。

适合这些场景：

- 📚 有完整大纲，想让 AI 按细纲逐章出稿，自己只做取舍和润色
- ✍️ 日更压力下，用「写本卷」批量生成整卷草稿打底，再逐章精修
- 🧠 长篇写到几十万字，怕人物设定崩、前文伏笔忘——让出场记忆替你盯着
- 💡 灵感来了随手记进灵感库，回头一键并进大纲
- 📤 写完直接导出 md / txt / 分卷 / docx / epub 去平台发布

不适合：指望一句话生成一整本拿去直接卖。AI 出的是**按你的细纲写的草稿**，成稿质量取决于你给的大纲和把关。

## 六大功能

### ✍️ 写作台 — 章级编辑与自动保存

- CodeMirror 6 编辑器：流畅长文输入，自动保存不打断打字
- 每章独立字数统计、章节历史快照（最多 20 份），写崩了随时回滚
- 大纲页直出「作品健康度」：卡文、断更、要点缺失一眼看清

### 🤖 AI 工坊 — 按细纲代笔，字数可控

- **写一段 / 本章草稿 / 写本卷 / 写全书**：从单段到整卷批量出稿，每章字数 300–5000 自定义（默认 2000，网文单章标准）
- 续写、润色、扩写、本章整理、视角实验、张力分析、简介与标题生成
- **内容门禁**：要点太薄的章会先提醒再生成，避免 AI 现编剧情掉回套路
- **提示词覆盖**：每类任务的自定义提示词，写谁像谁
- 批量进度实时显示当前章、成功/失败与缓存命中率

### 🧠 出场记忆 — 长篇不崩人设

- 采纳章节后自动抽取出场人物/物品/事件，写进人物卡与设定卡
- 人物状态与履历自动追加，幻觉角色一键清洗
- 伏笔从埋设到回收全程追踪，牵线画布可视化人物关系

### 🗂 大纲与灵感 — 书 → 卷 → 章

- **书 → 卷 → 章**三级结构：导入大纲文件（md/txt/docx）自动识别卷标、建卷建章
- 「并入大纲」按章名把大纲段落分发到对应章的剧情要点
- 灵感库随手记，一键并入大纲或新建作品
- 场景板按空行切块重排章节结构，牵线画布梳理人物关系

### 🎲 卡池与取名 — 灵感不再枯竭

- 卡池抽卡出设定灵感，卡牌可收藏进设定
- 取名大师：中文人名/地名/功法批量生成，钉住常驻抽屉

### 🗃 数据安全 — 全本地，可迁移

- 自动保存 + **每日自动备份**（保留 7 天）+ 设置里一键从备份恢复
- **数据文件夹一键迁移**：设置里换个位置，自动搬全部数据与备份并重启
- 导出：md / txt / 分卷 / docx / epub；Obsidian 库双向同步

## 使用方式

1. **下载安装** → [Releases 页面](https://github.com/7SteveJohn/PaiAn/releases/tag/v1.0.1) 下载「拍案-安装包-1.0.1.exe」，或免安装便携版
2. **接 AI** → 设置里选本地 Ollama（一键填好、0 成本），或粘贴任意 OpenAI 兼容 API（DeepSeek / 智谱 / Kimi…），Key 只存本机
3. **建书导大纲** → 新建项目 → 导入大纲文件，自动建卷建章
4. **批量出稿** → 选中卷点「写本卷」，逐章审阅采纳，导出发布

> **注意**：AI 生成的草稿都落在「待审草稿」里，**采纳才进正文**，原正文会先存快照——AI 永远不会背着你改稿。

## 技术细节

- **架构**：Electron 44 + React 18 + 本地 Node 服务，数据为本机 JSON 文件（每日备份，保留 7 天）
- **AI 协议**：OpenAI 兼容 SSE / Anthropic 原生 / Ollama 原生，32 家厂商预设，提示词流式输出
- **隐私**：无遥测、无上传、无账号系统；卸载即数据仍在你的文件夹
- **开源协议**：MIT License

- **导入面板新增「并入大纲」**：按章名把大纲段落分发到对应章的剧情要点，对不上的并入备注
