# 拍案 · 创作工作台

一个**纯本地**的文字创作工作台：灵感库、创作项目、AI 协同创作、统计复盘，四大模块一体化。
「拍案」取自「拍案惊奇」——愿你写出的东西，配得上每一次拍案。
数据全部保存在你自己的电脑上，不上传任何服务器；AI 功能调用你自己配置的大模型 API。

## 快速开始

1. 双击 `启动拍案.bat`（需要已安装 Node.js）
2. 浏览器会自动打开 http://127.0.0.1:4321

手动启动（等价）：

```bash
node server.js
```

## 桌面版（Windows exe）

最新产物放在**最近一次 `npm run dist` 自动选中的 `release*/` 目录**里（NSIS 安装包 + 免安装便携版，Electron 封装，内嵌本地服务，双击即用，无需装 Node）。数据目录默认在 `%APPDATA%/创作工作台/data/`。想知道当前是哪一份：`npm run check:parity` 会把比对的目录名打在结果里。

> 产物目录不用自己记：`npm run dist` 每次挑一个当前写得进去的目录，`check-parity.mjs` / `check-dist.mjs` 再自动找最近产出的那一份，所以 `dist:verify` 一条命令跑到底即可。`package.json` 里的 `build.directories.output` 只是「手动直接跑 electron-builder」时的默认值（`release`），实际目录由 `scripts/dist.mjs` 现场决定。
>
> 正常情况下本机只会留一份产物目录：每次打包先探上一轮的 `app.asar` 能不能改名，能改名就原地复用同一个目录，被第三方进程占住时才会顺延出一个新目录。多出来的旧产物（`release*/` 已在 `.gitignore` 里）只占磁盘，确认不用可以直接删。

**关闭保护（最小化到托盘）**：点窗口右上角 X **不会退出程序**，而是隐藏到系统托盘常驻——写作工作台是长驻工具，误关容易中断会话。需要彻底退出时：右键托盘图标 →「退出」。托盘建不起来（个别无托盘服务的环境）或崩溃恢复对话框选「关闭」时仍会正常退出。

**GPU 兼容模式**：个别环境（虚拟机 / 远程桌面 / 老旧显卡驱动）下窗口可能白屏或闪退。此时用兼容模式启动——关闭硬件加速、改用软件渲染：

- 给快捷方式/启动命令追加参数 `--disable-gpu`；或
- 先设环境变量 `WB_DISABLE_GPU=1` 再启动。

若界面已崩溃，应用会弹窗提供「以兼容模式重启」，一键完成。代码入口：`electron/main.cjs` 顶部 `gpuOff` 判定。

重新打包并自检：`npm run dist:verify`（= `npm run dist` 打包 → `scripts/check-parity.mjs` 校验包内容与源码一致 → `scripts/check-dist.mjs` 让解包 exe 自己跑 `--smoke-test`）。

两个本机踩过的坑：
- 在本助手的 bash 里打包前须 `env -u NODE_OPTIONS` 剥掉注入的环境变量，否则清理 dist 缓存会被安全删除 shim 拦住。
- 若报 `app.asar: The process cannot access the file`，是上一轮产物被第三方进程占用（杀软/云盘）——这一步现在不用你处理：`npm run dist` 走 `scripts/dist.mjs`，它先把最新 `release*/win-unpacked/resources/app.asar` 改名再改回来探一次，能改名就原地复用那个目录，不能就顺延换下一个空闲名字（`release` → `release2` → `release3` …），并把「选了哪个目录、为什么」打进日志。因此不再需要手写 `-c.directories.output=releaseN`；只想看它会选哪个，跑 `node scripts/dist.mjs --dry-run`。命名仍是 `/^release\d*$/`，`check-parity.mjs` 与 `check-dist.mjs` 的自动定位逻辑不受影响。

## 功能说明

- **写作页**：CodeMirror 6 编辑器（Obsidian 同款内核），自动保存、实时字数与目标进度；Markdown 一键预览；专注模式；Ctrl+F 查找替换；「写作 / 场景 / 大纲 / 牵线 / 复盘」五模式顶部切换。
- **场景板**（写作页「场景」模式）：把本章按空行切成场景卡片，拖着重排顺序、或整块搬去下一章——改结构时不用在几千字里拖选中再剪切。只有一块时会退到段粒度（你用单换行分段的话）；每次挪动都有一行回执和「退回上一步」，跨章那一步退回时**两章一起回**，不会把同一段留在两章里。切块与拼回是纯函数（`src/scenes.ts`），断言钉着「拼回去与原稿逐字节相等」：CRLF、段间多个空行、章末空行都不被规整，重排全章字节数不变。
- **首页**：启动即见——时段问候、四格统计磁贴（项目/灵感/累计产出/待回收伏笔）、「继续写作」断点卡、最近项目、四大能力入口（AI 引导创建 / AI 对话 / 灵感速记 / 统计复盘），全部能力第一屏可见。
- **正文标记系统**（不污染原文，导出自动清除）：选中文字弹出悬浮迷你菜单，可标为**伏笔 / 彩蛋 / 人物 / 场景 / 碎片**；正文侧边显示彩色细线；标记随编辑自动跟随（原文大改后标记失效并提醒）。
- **右侧素材抽屉**（写作页「素材抽屉」按钮，Esc 收起）：**伏笔追踪**（埋下/回收状态、预期章节、未回收亮小点）；**碎片箱**（标记片段 + 关联素材，一键插回正文）；**人物卡**（当前心理状态、境界/战力与绑章节的变更记录、阶段履历、关系备注）；**设定卡**（地点/道具/设定/势力/功法/力量体系，模板快建 + AI 整理导入）；**彩蛋管理**（注释只在导出带注释阅读版时出现）；**分支沙盘**（当前正文存为剧情分支，打标签 备选/待扩写/废弃，可插回光标处或搬回主稿，主稿自动先存快照）；**禁用词练笔**（命中的词浅灰波浪温和提醒，不强制删改）。
- **取名面板**（抽屉「取名」页签，`src/names.ts` 本地词库）：要什么（人物男女 / 别号 / 势力 / 功法 / 地名 / 器物）× 气质（玄幻 / 古言 / 都市 / 西幻）× 单双名，一次翻 6–24 个，每个都带一句「为什么这么拼」的注。**不联网、不调模型**，换一批只是换个种子（种子会显示出来，同种子永远同一批，所以能写断言）。看顺眼的点「钉住」攒着，一键把钉住的建成人物卡 / 设定卡（分类按词性自动归位）；本书已用过的名字（人物卡 + 设定卡 + 各章出场名单）生成时一定绕开——重名不出现，同姓同尾字还会撞，那正是挑的时候要看一眼的。
- **牵线工作流**（写作页顶部「牵线」模式，`src/graph.ts` + 手搓 SVG 画布，无第三方图形库）：把章、人物卡、设定卡、伏笔标记、便签摆成节点，用线牵出因果。节点存的是**引用**而不是复制——改人物卡不必回来同步，实体删了图上的影子会自动消失。「一键牵线」从已有数据长出能确定的那几条：章→章推动（按顺序）、章→出场人物（按每章出场名单）、人物→人物（按关系卡）、章→伏笔（按埋点章），**重复点不会堆重复线**。可以像 ComfyUI 那样从节点右边的输出点拖到另一个节点上手牵一条，类别可选 推动 / 出场 / 关系 / 伏笔 / 手牵。选中一个章点，右侧「沿链取用」顺着线往回追 N 章，拼出「前章要点 → 链上人物与状态 → 链上伏笔（含未收）→ 落点」，可复制或一键写进该章剧情要点；侧栏还常驻**断线诊断**：未收伏笔、谁都没连上的实体、中间断了推动线的章。拖动即存坐标，「整理布局」一键按阅读顺序摆齐。**「演一遍」**把这张图当剧本放：沿「推动」线一拍拍走（起点是没有前章的那一章，线断了不猜、按目录把剩下的章补在末尾并明说这一段没接线，手滑牵出环也不会挂死），镜头跟着这一拍平移（0.45s 过渡），其余节点压到 32% 透明、当前这拍描金；画布上方占一行的字幕条报「第 N / M 拍 · 章名 · 这一章讲什么」，没写的章标成空拍，侧栏给出在场人物、挂着的伏笔与牵到本章的便签，可以手动上一拍／下一拍，也可以中途「去写这章」。每拍默认停 2.6 秒，慢 / 中 / 快可切，走到最后一拍自己停（循环播放会变成背景噪音），`Esc` 随时收工。
- **复盘模式**：伏笔总览、主题关键词统计（高频意象词）、简易基调统计（负面/正面事件词粗计）、人物关系图谱（环形布局）、**AI 味（模板句式）**统计与密度最高的章、**设定守夜人**（境界回退 / 称谓一致性 / 远场沉默）。
- **节律区**（复盘模式顶部，`src/pitch.ts` + `src/debt.ts`，全本地确定性统计、不调模型）：三块共用一份每章统计，只吃你已经写下的东西。**节奏琴键**——已写章节按顺序一章一格，条高=平均句长（拿本书中位句长当基准线归一，顶到最上只代表「明显比中位长」）、颜色深浅=对白占比、条顶小点=这章收在台词上、条底暗条=AI 味每千字密度，整卷扫过去像琴键，连着七八根等高就是节奏平了，悬停看这一章的句长/对白/说话人；超 90 章默认只画最近 90 根，可「看全本」。**对白天平**——这段范围里谁在说话：靠「名字+说话动词/冒号」紧贴引号前后 40 字来归属，两边都命中取更近的，排出行数条形；**认不出就说认不出**，另报「归属不明 N 行」而不摊到某个角色头上，底下附「这些人消失了」（连续 5 章以上既没开口也没被列进出场名单）。**伏笔利息**——每条未回收伏笔按「埋点之后又写了多少字、挂了几章」计息（挂过 4 章「该想想」、9 章「该收了」、18 章「快烂尾」），点「把最欠的掉成收线卡」丢进卡池，抽到打出去就把这条挂进本章「伏笔安排」；卡 id 由伏笔标记决定，重复点不堆重复卡。
- **设定守夜人**（复盘模式第二屏，`src/watchdog.ts`，同样全确定性、零 token、不联网）：长篇真正的塌房不是写慢，是自己跟自己矛盾。三块账——
  - **境界线**：先从你写的「力量体系」词条里抽境界序列（`炼气 → 筑基 → 金丹 → 元婴`），词条没排成序列就退回内置的三条常见线（炼气→渡劫 / 斗气 / 武者）。然后在正文里找境界词，**只算叙述、只认唯一归属**：台词里说的、「还没筑基／当年他还是炼气」这类否定与回忆、境界词单独成句而本句没有人名、一句话里挨着两个人名的——一律不算到谁头上，并且如实报「挡掉了几处」。判三种不一致：**往回走**（第18章金丹、第28章写回筑基中期）、**同章打架**（一章里既元婴又金丹）、**卡落后正文**（卡上筑基，正文已金丹）。每条都带章号和那一处原话，不给你猜。自创体系（不走炼气筑基那一套）判不了的时候不留一句干提示——面板直接给一个「补一张力量体系卡」的入口，一键建出带 `→` 写法的脚手架设定卡，你把序列改对，下一趟同步、注入与判定就全用你自己的线（建过就不再劝，避免变成 nag）。
  - **称谓与名册**：两个名字互为子串、或开头/末尾撞两个字，报「易串」（只报都在正文出现过的；只同姓一个字不算）；建了卡却全书没出现过这个名字，报「卡没落地」；出场名单写了名字、正文里却没有这个字，报名字与章号（名单里你自己标了「未露面」的，当他知道，不重复报）；关系栏指向没建档的空名，报「指向空名」。
  - **远场沉默**：每个人物卡与设定卡都算「首次出现 / 上次**进场** / 距今几章 / 中间隔了多少字」，隔过 6 章才报——**别人台词里提起他一次，不算露面**：只在对话里出现过的名字单独标成「一次也没进场」（这种卡要么让他真上一次场，要么删掉，留着就是资料库在骗你），进过场之后只在台词里被提到的，也会写出「其间被提起 N 次」。这就是「第 1 章那枚铜钥匙到第 28 章还认不认得」的常规化，不靠模型自觉。
  - **只报不改**：一个字都不动你的正文。会动的只有卡：可动笔的三类（回退 / 没落地 / 沉默）一键掉进卡池，卡 id 由发现本身决定，重复点不堆重复卡。它也不只给面板看——算出的「每个人物已经写到的最高境界」会当设定红线注入每次 AI 调用，并接进批量生成的前置门禁（见「战力绑定章节」那条）。**实测**：合成 30 章、埋 6 处事故 + 5 类诱饵的夹具，6 处全检出、诱饵 0 误报；示例书 5 章 0 报错——顺手修掉了两个从真实文本里量出来的误报（境界词被下一句的人名偷走、名单括号注释当成漏写）。
- **AI 只判不写**（设置页一个开关，默认关，存在 `data/ai.json`）：开着时 AI 不当笔、只当镜子——「续写」改成给 3 种走向与各自的后果与代价、「润色」改成逐条指出哪一句有什么问题、往哪儿改（不替我重写整句）、「扩写」改成判断这段薄在哪儿、给 3 个可补的方向；批量生成草稿与单章「生成草稿」按住不给按，结果区也收起「插入文末 / 替换所选」，免得把分析粘进稿子。分析类（联想词云 / 感官检视 / 视角校验 / 张力分析 / 风格采样）与游戏改编类本来就不产出小说正文，不受影响；已经存在的待审草稿仍可照常采纳或丢弃。那句「只判不写」插在**写作规则之后、作品语境之前**，所以批量连写时公共前缀照旧不断（`tests/prompt-cache.test.ts` 带正反两条断言）。适合「不许 AI 替我写，但要它天天挑我毛病」的写法。
- **AI 味自检**（不联网、不调模型、不花 token）：内置 10 条确定性模板句式规则（「不是A，而是B」「，带着…」万能状语、「声音不大却…」、一丝…划过、仿佛…一般、段首总结、破折号插入语…），命中处在正文里画**细虚线**，正文一个字不改。写作页底部「AI 味（n）」可展开明细：毒级排序、每千字密度、修法、点命中处直接跳转；AI 工坊每次生成完会给这段结果做一次自检；复盘页按章汇总找最重的几章。**对白豁免**：引号内的命中一律不报（「不是A，而是B」出现在口语里是正常中文）。不想被打扰就在面板里点「写作时不再提醒」，可随时恢复。
- **抗拖延**：**冻结修改**（锁定光标前正文，只能向下续写，防止反复回改）；**断点记忆**（退出自动记录光标位置，项目列表顶部出现「继续写作」卡片，点击直接回到现场）。
- **AI 工坊**（辅助不替代）：续写 / 润色 / 扩写 / 起标题 / 生成大纲，外加**联想词云**（只出氛围意象词）、**感官检视**、**视角校验**、**张力分析**、**风格采样**（只给分析与方向，不生成成品台词/句子）。支持**抽卡模式**：一次并行生成 3 个方案并排对比，点卡片采纳后再插入/替换；输出中的【金手指】【伏笔】【爽点】等要素自动渲染为高亮标签。
- **AI 引导创建**：新建项目可走 AI 向导——输入一句灵感，AI 分步生成「核心设定 → 主角 → 故事大纲」各 3 个方案供点选采纳（可跳过/换一批），完成后自动创建带完整备注的项目。
- **大纲模式与批量写作**：章节大纲是结构化实体——每章带「剧情要点 / 出场人物 / 出场地点 / 伏笔安排」，可 AI 一键拟多章（JSON 解析带回退），也可逐字段手改；**批量生成只产草稿不进正文**：勾选待写章 → 逐章顺序生成（前情摘要 + 未回收伏笔 + 本章大纲 + 战力变更记录自动注入上下文）→ 每章「看草稿 → 采纳为正文（原稿先存快照）/ 重试 / 弃用」人工卡点；摘要自动截取，可一键「AI 提炼摘要」精修；全书大纲可一键复制备份。**批量生成前置门禁**：选中的章里若有人「剧情要点」还是空的（细纲不足 12 字），或挂着未采纳的旧草稿（会被覆盖），点批量时先拦住给三条路——去补要点 / 只生成有细纲的 / 照常全部，细纲没到位的章输入框是虚线，一眼看出哪章还没想清楚；单章「生成草稿」不拦（偶尔想看 AI 随意发挥是正当需求），整体开关在设置页。采纳草稿成文时若字数不足目标 6 成，会在该章卡片下提一句欠账。
- **时间线**：大纲面板「时间线」视图——逐章标注故事内时间（timeLabel），可 AI 批量推断全书时间标签（预览可改再应用），防时序混乱。
- **章节剧情探讨**：每章卡片内置迷你对话，与 AI 剧情策划写前敲定本章剧情（只讨论不写正文，记录随章节保存）；结论一键「落为要点」，替换/追加经确认后才写入大纲。
- **设定卡与 AI 整理导入**：世界观词条卡片化为六类（地点 / 道具 / 设定 / 势力 / 功法 / 力量体系），按模板快建（势力卡、功法卡等脚手架）；「AI 整理导入」把随手贴的混乱资料整理成结构化设定卡，逐条检查后入库（同名跳过）。
- **战力绑定章节**：人物卡记录当前境界与战力变更（绑到具体章节），升级线自动注入 AI 上下文并声明「不得跳级或倒退」，防战力崩坏。卡上没记 `powerLog` 也不管用——**守夜人会直接从已写正文里算出每个人物「已经写到的最高境界」**，作为一段「设定红线」注入上下文（`· 林越：不低于「金丹」（正文第1章已写到）`，封顶 8 行），并且把它接进批量生成的前置门禁：批量按钮按下去时如果正文里有境界前后不一，面板会一并列出（带章号），提醒你先回头改稿——因为 AI 拿到的是这条红线，红线本身错了就得先修依据。
- **规则中心**：设置页自定义写作规则（文风约束、禁则、世界观红线），启用后自动注入所有 AI 调用（工坊动作与对话）。
- **出场记忆（自动抽取）**：批量生成草稿被「采纳为正文」后，自动调 AI 抽取本章出场的状态变化 / 战力升级 / 新角色 / 新关系 / 新设定，校验（出场名单双向核对、防幻觉）后写回人物/设定卡，让 AI 长跑几百章不丢人物状态。可在设置页关闭。
- **AI 对话**：独立对话工作台，多会话管理、流式回复、Markdown 渲染、历史持久化（`data/chat.json`）。
- **历史版本**：每天首次编辑自动存快照，AI 改写前强制存快照，最多 20 份，可回滚；**可对比**——每份快照一键「与当前正文对比」（`src/version-diff.ts`，纯本地零 token）：段落对齐后整段标红删除线/标绿，被改过的段再做字符级精比（「散步」改成「跑步」只标那一个字），被删的段落整段可选中复制走，头部报 −删/＋增 字数。整段重写时不下钻成满屏碎屑，相似度不够就整段成块；超大文本有 maxEditLength 与超时双闸，最坏退化成整篇旧稿/新稿两块，绝不会卡死。
- **回收站**：删除的项目与灵感可恢复或彻底删除。
- **全局搜索**：搜项目标题/正文/备注与灵感内容，项目结果直达写作页。
- **每日目标**：目标字数 + 写作页底部实时进度。
- **统计复盘**：累计产出、今日新增、连续天数、近 14 天产出图、近 20 周热力图、项目状态分布、复盘笔记、**分章字数**（选一部章节作品，按卷列出各章字数条形图与平均篇幅）。
- **夜间模式**：全站含编辑器与对话跟随；主题在首屏之前就已写进 DOM，窗口也等首帧画好才亮出，启动不再闪一帧浅色。
- **分卷**：章节可填「所属卷」，大纲按连续卷名自动分组并显示卷内章数与字数；卷名可整卷重命名，改中间某章的卷即拆卷。导出时自动插入卷标题。
- **桌面版标题栏**：窗口不再带系统那条白底标题栏（它和米色正文之间有一道硬分界）。顶 40px 是页面自己的拖拽区（双击最大化），右上角仍是最小化 / 最大化 / 关闭三个**原生**按钮——贴边吸附、Win11 布局推荐都还在；按钮底色与符号色跟主题一起翻。用浏览器或 `启动拍案.bat` 打开时这些规则一条都不生效。
- **数据安全**：启动自动备份到 `data/backups/<日期>/`（保留 7 天）；手动导出全量 JSON，**并可从备份文件整包恢复**（写盘成功才替换内存数据）；打开数据目录；复制全文 / 导出 `.md` 或 `.txt` 分章版（含卷/章标题，内部标记全部清除，TXT 用 Windows 换行可直接投稿）。
- **接口安全（本机同源闸）**：服务只绑 `127.0.0.1`（局域网进不来），但光绑地址挡不住**浏览器**——你打开的任何网页都能对 `127.0.0.1:4321` 发请求，而跨站的「简单请求」根本不走 CORS 预检。所以 `/api/*` 自己认同源：`Host` 必须是 `127.0.0.1:端口` 或 `localhost:端口`（顺手堵住 DNS rebinding）、带 `Origin` 就必须同源、带请求体就必须声明 `application/json`。修前的实测形状是：带 `Origin: http://evil.example` 的 `text/plain` 版 `PUT /api/data` 能直接改你的书，`POST /api/ai/chat` 能被当成免费代理烧 token，最坏的一条是跨站先 `PUT /api/ai-config` 把 `baseUrl` 换成别人的地址、你下一次正常调用就把 Key 送出去了，另外 `GET /%` 一个畸形 URL 就能让进程退出——现在这几条都有断言守着（`npm run test:api` 的「同源闸」一项，含同源正常写的正例与被拒之后配置没变，不是只测拦）。API Key 只存在 `data/ai.json`，只出现在发往**你自己配的那个 `baseUrl`** 的请求头上：接口回给界面的一直是 `hasKey: true`，`GET /api/export` 也不含 `ai.json`——所以「导出 JSON 丢进同步盘」不会把 Key 带出去。
- **卡池抽卡（边玩边写）**：侧栏「卡池」页，内置 46 张卡分五系列——小事（N，一句就能落地）／岔路（R，两个你已写过的元素被迫相撞）／破格（SR，一次叙事手法）／大局（SSR，跨卷局面，自动铺进后续未写章）／练笔（条件本身就是奖品，靠达成率点亮）。**货币就是你写的字**：净产出每 1000 字换一抽，完成当日目标额外送一次；因为走的是净产出口径，删了再写刷不出抽。
  - **卡是真的有效果**：打出后直接改数据——写进本章「剧情要点」／「伏笔安排」／出场名单、加入禁用词练笔、追加到规则中心（之后每次 AI 调用都带上）、或整条铺进后续章。单篇模式没有这些栏，就落到作品备注。
  - **卡面会取你自己书里的东西**：`{char}` `{place}` `{item}` `{hook}` 槽位在打出时从当前作品的人物卡、设定卡、未回收伏笔里取，所以同一张卡用在两本不同的书上，任务并不一样。
  - **点亮**：打出去不等于点亮，正文真做到才算（约束类看禁词还在不在，行为类看该写的有没有写），由 `src/deslop.ts` 那套确定性检核判定，不叫模型。
  - **动效与概率**：卡背逐张翻面、稀有度决定描边与光柱、SSR 加金光与一次轻震、十连 stagger 排开；点任意处立即全部翻开。概率、保底（30 抽必出 SSR）、重复卡转「墨」、墨可**定向换一张**（救济通道，不是商店）全部写死在 `src/cards.ts`，界面照抄公示，没有后台调率；无付费、无限时、无体力。
  - 抽到的卡进「在手」（最多 3 张），显示在写作页顶部；**专注模式会整条收起手牌**，写正文时不该有发光的东西可点。系统开了「减少动效」时翻牌与金光自动停用。
  - 卡池可以改：内置卡可以一张张勾掉（某张老干扰你就让它不出），也可以自建卡进池；都存 `data/cards.json`。
  - **约束类卡有达成率**（「练笔」系列 + 部分小事/岔路卡）：条件是可判定的确定性检查——叙述句长度上限、对白占比区间、以「他/她」开头的段数、某种 AI 味句式最多几处、必出现/禁出现的词。打出去之后卡挂在手牌条上显示 `0/2 → 1/2 → 2/2`，**写到达标那一刻自动点亮**；不达标期间它只提醒，不拦你。统计一律只看叙述段，引号里的对白不参与句长与段首人称判定。
  - **AI 也得守你的约束**：句长/对白/段首这类需要理解语义的条件，打出时会自动进规则中心（与卡牌规则共用 6 条上限），否则 AI 一键续写就把你定的节奏打回去；纯词表类不进规则，正文里已有浅灰提醒。
  - 打出的卡如果暂时不想被追，可以在手牌条上点「放弃」——卡仍算你抽到过（留在图鉴），只是不再要求达成。
- **拆文对标**（卡池页底部，同样纯本地）：把一本参考书的正文贴进来，按「第N章」自动分章（认不出就按空行分），拆成**每章几个数字**——平均句长、最长句、对白占比、段首人称密度、章末是否落在对白上、各类 AI 味句式每千字几处。**原文不存**，只存统计（对标一本 500 章的书也就几十 KB），因此 `data/benchmarks.json` 里翻不出别人的正文。选一部自己的书并排比，差距过线的标「值得学」，一键**掉成卡**进池子：卡面写着「对标《某书》——它对白占 33%，你 8%」，条件是可判定的（`对白≥23%`），下次抽取就可能抽到它。掉卡是幂等的：同一次拆解的卡 id 固定，重复点不会堆重复卡。两边各不足 3 章时直接说「比不出名堂」，不硬给结论。
- **笔触漂移**（拆文对标的下面一块，尺子完全同一套）：对照物换成**你自己**——基准优先取你其它作品里够长的已写章，只有一本书时退回本书前段；看的对象是最近 3–8 章。句长、对白占比、段首人称、章末落点、单章篇幅、AI 味密度逐项列「惯常 / 现在 / 偏了多少」，过线的标「偏了」。同样一键掉卡，只是卡面把「学它」换成「找回」：`找回：句长压到 6 字`、`找回：对白占到 38%`，条件照样可判定。不足 3 章对 3 章时直说比不了；正文不足 150 字的章不进统计（一段随手标注会把中位数整个带跑）。长篇真正的风险常常不是写得像别人，是写着自己变了。
  - **合成两卡**：手上有两张卡时可以「合成两卡」，把最左两张并成一个**本章组合任务**（不消耗卡、不额外发抽）。同一维度的条件冲突时取较松的一侧，并在卡面写明谁让了步（「对白占比取了两头的并集」）；组合任务**达成时白送一次抽**——先花奖励次数，再按字数记账。手牌条上可以随时放下。
- **快捷键**：`Ctrl+K` 全局搜索、`Ctrl+S` 立即保存、`Ctrl+F` 查找替换、`Esc` 退出专注模式 / 收回抽屉 / 收掉正在演的「演一遍」（暂停用按钮，Esc 是收工）。
- **Obsidian 双向同步**：导入库内笔记为素材；一本书同步成一文件夹（书名/章节/人物/设定各一文件 + 索引页），三方对比后只推该推的、只拉该拉的，两边都改过就判冲突让你逐条选，绝不静默覆盖。

## 配置 AI（云端 API 或本地模型）

参照 Cherry Studio 的模型服务形态，设置页内置 **30+ 供应商预设**，按分组下拉选择：

- **国内云**：DeepSeek / 通义千问（百炼）/ Kimi / 智谱 GLM / 豆包·火山方舟 / 腾讯混元 / 百度千帆 / 讯飞星火 / MiniMax / 阶跃星辰 / 零一万物 / 百川 / 硅基流动 / 魔搭 ModelScope / 小米 MiMo
- **海外**：OpenAI / Anthropic Claude / Google Gemini / xAI Grok / Mistral / Groq / Together / Perplexity
- **聚合中转**：OpenRouter / 302.AI / 自定义（OpenAI 兼容）/ 自定义（Anthropic 协议）
- **本地**：Ollama / LM Studio / vLLM / Xinference / LocalAI / Jan

除 OpenAI 兼容协议外，还内置 **Anthropic 原生协议**（`/v1/messages`）适配——Anthropic 官方、百度千帆与 MiniMax 的 Anthropic 通道、one-api/new-api 的 Claude 通道均可直连，流式输出会自动转换。

**订阅制 / 非标准 Key**：部分厂商有独立的订阅接入点与专属 Key 格式，预设里一键切换、输入框按方案提示格式，格式不符会软提醒（不拦截）：

- 小米 MiMo：按量付费 `sk-…` ↔ Token Plan `tp-…`（中国 / 新加坡 / 欧洲三个接入点）
- 智谱 GLM：标准计费 ↔ Coding Plan 订阅接入点；Key 为 `id.secret` 格式
- 讯飞星火 Key 是 `APIKey:APISecret` 拼接；MiniMax 是 JWT（`ey` 开头）；魔搭 `ms-`、Gemini `AIza`、xAI `xai-`、Groq `gsk_`、Perplexity `pplx-`、OpenRouter `sk-or-`

**云端 API**（OpenAI 兼容）：

1. 打开「设置」，下拉选供应商（或点顶部快捷入口），粘贴 API Key（预设旁有「去申请 Key」直达链接）
2. 点「获取模型列表」可直接选择该账号可用的模型（也可手动填写；预设自带常用模型快捷标签）
3. 点「保存并测试连接」

**个别供应商注意**：豆包/火山方舟的模型名填控制台「推理接入点」ID（`ep-` 开头）或模型 ID；讯飞星火的 Key 填 `APIKey:APISecret`（冒号拼接）；各家接口地址可能调整，改「接口地址」输入框即可，无需等更新。

**Ollama 本地模型**（无需 API Key，完全离线）：

1. 安装并启动 Ollama（命令行 `ollama serve`，或开启桌面端；默认端口 11434）
2. 下载模型：`ollama pull qwen2.5:7b-instruct`（或其他模型）
3. 工作台「设置」里选「Ollama（本地）」→ 点「获取模型列表」选择模型 → 「保存并测试连接」

Key 只保存在本机 `data/ai.json`，AI 请求由本地服务直接转发给厂商/本机 Ollama，不经过任何第三方。

## 接入 Obsidian 知识库

工作台可以直接读写你的 Obsidian 库（Vault）文件夹，**无需安装任何 Obsidian 插件**：

1. 打开「设置」页，在「Obsidian 知识库」填入库文件夹路径（如 `D:\Notes\MyVault`），可指定库内子文件夹存放同步产物，点「保存库配置」；旁边有「在 Obsidian 里打开」直接跳过去（桌面版走 `obsidian://` URI，没装 Obsidian 就退回打开文件夹）
2. **导入**：灵感库 → 「从 Obsidian 导入」，按文件名搜索库内笔记，预览后决定它落到哪里。导入这一侧讲五件事：
   - **认得出自家导出**：带 `wb-id` 的文件是工作台同步出去的镜像，列表里标「工作台导出」并沉到原创笔记后面，按钮改成「仍要导入这份镜像」——导入自己的导出通常是白干，但按下去的权利还在你手上
   - **导过的看得见**：卡上记 `Idea.src`（库内相对路径），灵感卡底部显示来源，再开面板同一篇标「已导入 N 条」，按钮跟着说「再导一条」
   - **只带走正文**：属性区（`---` 头部）和我方维护的 `<!-- wb-notes -->` 批注区都剥掉，换行统一成 LF；剥了什么会写在预览上方，不静默改你的字
   - **落点可选**：不止进灵感库——同一篇笔记可以**建成设定卡**、**新建一章**（库里写好的章直接搬进来），或**并进某一章的「剧情要点」**（要点是短行，所以带上 `〔库·文件名〕` 前缀并压成一行，且绝不顺带改正文）。选设定卡/新章时「叫作」预填文件名、可以改；这本书里已经有同名的会提醒你，但不拦你
   - **有上限**：一次最多扫 800 篇匹配（超了明说「缩小搜索词」），单篇超过 4MB 直接拒绝读取，预览超 12000 字截断并注明「导入的是全文」
3. **双向同步**：写作页点「同步」，或项目列表点「全部同步」。想省事就在设置页开**自动同步**（默认关）：写作页停下 12 秒自己推一次，判据照旧走三方对比；**遇到冲突它就停手**，等你在右下角点完再继续——自动的东西不替你选边，**点了「先不管」把清单收起来也照样停手**（收起只是不显示，不等于没冲突），回执会告诉你点「同步」能把清单再拉出来。关着时只有你点按钮才动库里的文件。一本书在库里是一个目录，**一物一文件**：

   ```text
   工作台/雾港/
     index.md            索引页（MOC）：链到每一章、每张卡
     章节/第1章 到港.md    每章一个文件，frontmatter 带 chapter-no / volume / beats / cast / hooks
     章节/第2章 黑车.md
     人物/林越.md          人物卡：当前状态、境界、关系、情绪履历
     设定/北窗.md          设定卡（地点/道具/势力…）
   ```

   正文里已建档的人物与地点自动写成 `[[人物/林越]]`、`[[设定/北窗]]`，所以 Obsidian 的**图谱、反向链接、悬浮预览**直接能用；每篇的 frontmatter 带 `wb-id` / `wb-kind`，认文件只认这个 id，不靠文件名。

4. **两边都能改**。每次同步拿「上次写入内容的指纹」当共同祖先做三方对比：

   | 情况 | 结果 |
   | --- | --- |
   | 只有工作台改了 | 推过去（覆盖那篇文件） |
   | 只有库里改了（在 Obsidian 里编辑、续写） | **拉回来**：章节正文、人物状态/境界、设定内容落回作品，界面走自己的保存路径 |
   | 两边都改过 | 判**冲突**：既不动文件也不动数据，右下角列出清单让你逐条选「用工作台这版 / 用 Obsidian 那版」 |
   | 工作台删了某章/某卡 | 只回收带 `wb-id` 标记的文件，库里别人写的笔记一个字节都不碰 |
   | 什么都没变 | 什么都不写（渲染是作品状态的纯函数，**不嵌时间戳**，否则每次同步都会把没动的文件重写一遍） |

   **写法不算改动**：Obsidian 的属性视图保存时会用 js-yaml 重新序列化属性区（标量去掉引号、数组写成 `- 项` 的块式列表、键序也可能变），这属于「同一个内容换了写法」。所以判「谁改了」用的是**正文指纹**——只看正文、批注区和我方认识的那二十来个键，别的手段一律看不见；否则他一存盘，整本书就被判成「库里全改过」，每趟同步都在空推空拉。
   **你加的属性归你**：在库里补的 `aliases`、`cssclasses`、自己发明的属性，同步既不会把它们当成内容改动（不触发推/拉/冲突），推的时候也会原样贴回文件，不会被工作台抹掉。
   你在 Obsidian 里加的 `> [!note]` 之类批注，同步时用 `<!-- wb-notes -->` 标记单独保管：**不算进正文**，下一趟再原样贴回文件末尾——否则「导出 → 批注 → 回读」两趟就把批注吃成正文了。批注按实体 id 存，章节改名也不丢。

**边界说明**：冲突判定需要人点，工作台绝不静默偏向任何一边；`data/obsidian-sync.json` 是祖先指纹表（每条带 `v: 2`，记的是正文指纹），删掉它最坏只是下一趟多问一次，不会丢内容。老记录（没标版本的）遇到「正文一致、写法不同」会静默升级成新指纹，不会把升级前同步过的书整本判成冲突。旧的「一本书一个 md」导出方式已被目录式取代——如果你库里还留着 `<书名>.md`，同步不会去动它，需要的话手动删。

## 数据与备份

- 所有内容以 JSON 明文保存在 `data/` 目录（`ideas.json` / `projects.json` / `versions.json` / `stats.json` / `gacha.json` / `cards.json` / `benchmarks.json` / `ai.json`），可直接阅读、编辑。
- **历史版本快照单独存 `versions.json`，并且按「哪一条变了」来回搬**：正文每 800ms 就可能整包重写一次，而实测一本 500 章的书里快照能占到包体的 93%（20 份日更快照 = 正文的 20 倍）。分文件之后再做两层：① 首屏 `GET /api/data` 只带正文与一份「每条快照 key 有几份」的份数表，快照全文等你打开那本书才 `GET /api/versions?project=…`；② 落盘走扁平线格式（key = `pid` 或 `pid::cid`），只有指纹变了的 key 才 `PUT`，空数组表示删除。合成 300 章 × 6000 份快照实测：**首屏 21.93 MB → 1.05 MB（4.8%）**，改一章的一份快照要上传 **20.88 MB → 67.8 KB（0.32%）**。护栏是「没读过的 key 绝不覆盖写回」——份数表说服务端有货而本地没读进来时，先去读、下一拍再发，宁可不发也不把别人的 20 份顶成一两份。老数据里的嵌入快照会在首次启动时自动搬过去（搬运发生在当日自动备份之后，备份即回滚点）。
- **删书删章会顺带剪掉孤儿快照**：整包 `PUT /api/data` 之后，服务端按最新作品/章节清单剪 `versions.json`，只数 key 不比内容（几十 MB 的文件不该每次自动保存都重 stringify 一遍）。
- **备份导出改由服务端拼装**（`GET /api/export`，带下载头）：客户端内存里已经不背快照了，让界面自己拼会导出一份缺快照的备份。「从备份恢复」照旧整包回灌（快照走 `mode: 'replace'`）。
- 整包保存有请求体上限，默认 96MB（中文按 UTF-8 每字 3 字节计，够百万字长篇带满快照）。超限服务端会明确回 413 与原因，侧栏「保存失败·重试」悬停即可看到那句话，不再只是「Failed to fetch」。要放宽就设环境变量 `WB_MAX_BODY_MB`（如 `set WB_MAX_BODY_MB=200 && node server.js`）。
- 数据文件被写坏或被手改坏时：原件会先另存为 `<文件名>.corrupt-时间`，接口以空数据继续并在响应里带 `warnings`，界面顶部出现黄色提示条——不会默默把清零当成你的新数据。
- **多窗口/多标签页同开**：保存是整包覆盖模型，从较旧状态出发的那一次写入会盖掉较新的内容。服务端会识别这种「写入比磁盘已有内容更旧」的情形并在响应里回 `stale`，界面顶部随即提示去 `data/backups/` 找回。这是识别与提醒，不是自动合并——同一本书别开两个窗口改。桌面版本身有单实例锁，只有用 bat/浏览器手动开多个标签页时才会遇到。
- 「设置」页可一键导出全量备份 JSON，也可用「从备份恢复」把备份整包写回（会覆盖现有项目/灵感/统计，恢复前有二次确认；写盘失败则保留原数据不动）。
- **多设备同步**：把 `data/` 文件夹放进 OneDrive / 坚果云等同步盘，然后这样启动：

```bash
# Windows PowerShell
$env:DATA_DIR="D:\OneDrive\创作工作台数据"; node server.js

# 或 CMD
set DATA_DIR=D:\OneDrive\创作工作台数据 && node server.js
```

（也可以把 `启动拍案.bat` 复制一份，在其中 `node server.js` 一行前加 `set DATA_DIR=你的同步盘路径`。）

改代码后怕改坏？按需跑这几条，全部通过再提交：

```bash
npm test          # 单测：纯函数 / 工具逻辑 + 组件 SSR 渲染（项数以输出为准）
npm run test:api  # API 冒烟：起真实服务 + 隔离数据目录，打全部本地接口
npm run test:ai   # AI 冒烟：本地假上游模拟三种协议，验证流式/缓存/降级（不连外部模型）
npm run smoke     # 一条龙：构建 + 单测 + API 冒烟 + AI 冒烟（日常提交前跑这条即可）
npm run test:ui   # UI 主路径：真实点击「新建作品 → 写正文 → 自动保存 → 校验落库」
npm run test:ui:gacha # 卡池 UI 冒烟：抽卡动效 → 保底/账本 → 手牌 → 打出效果落库 → 达成率与自动点亮 → 合成组合任务拿奖励抽 → 拆文对标掉卡 → 笔触漂移掉「找回」卡 → 批量生成前置门禁
npm run test:ui:mem  # 出场记忆闭环：采纳 AI 正文 → 假上游返回记忆 → 人物卡写回校验（含幻觉清洗）+ 采纳字数欠账提示 + 快照懒读与回滚 + 取名面板建卡与避重 + 牵线画布（一键牵线、拖拽存坐标、手牵线、沿链取用写回要点） + 快照懒读与回滚（断言首屏不带快照、面板仍列得出、回滚再留一份）
npm run test:ui:ob # Obsidian 双向同步真实窗口冒烟：进程外推树 + 按 Obsidian 的存盘方式改库 → 界面点同步 → 冲突面板点边 → 再推保住他的别名 → 全部同步 → 导入侧认镜像/记来源/剥属性区 → ④ 落点可选（设定卡、并进章要点，回盘上核对）→ ⑤ 自动同步（默认关；开了停下 12 秒自己推；进程外撞一次冲突验「停手 + 先不管也停手 + 判完收口」）
npm run test:ui:scene # 场景板真实窗口冒烟：真的 PointerEvent 拖一张卡换位（断言落点线、跟手压暗、落库一字不丢也不重复）→ 上移按钮精确挪 → 整块搬去下一章再「退回」（两章一起回）→ 空章不谎报 → 单换行分段退到段粒度（会说，也照样能挪） → 导入侧认镜像/记来源/剥属性区
npm run test:tray  # 关闭保护探测：真实窗口模拟点 X → 断言最小化到托盘而非退出
npm run dist:verify  # 打安装包 + 校验包内容与源码一致 + 让解包 exe 自己跑自检（最接近真实分发的验证）
npm run check:parity # 只校验「现有包」是否是当前源码打的，防止发到手的 exe 其实是旧代码
npm run smoke:ui  # 只验「能开机、能连数据」的快速自检（不跑主路径）
```

- **分层怎么用**：`test` 覆盖纯函数与组件渲染（`react-dom/server` 静态渲染，不引入测试库）；`test:api` 走真实 HTTP；`test:ai` 用假上游；`test:ui`/`test:ui:mem` 在真实 Electron 窗口里点真实按钮，写到临时数据目录、跑完即删。
- `test:ui:mem` 预置一个「章节模式 + 待采纳草稿 + 老角色卡」项目与假上游（固定返回含幻觉噪声的记忆 JSON），真实点击「采纳为正文」，端到端断言：老角色状态更新并追加履历、新角色建档并写入关系、正文未出场的幻觉角色被清洗、无关角色不动。
- `test:ui` 与 `smoke:ui` 都用隐藏窗口，不弹窗打扰；受限/远程桌面环境若遇 GPU 进程崩溃，附加 `--no-sandbox` 重跑。**注意它们加载的是 `dist/` 产物，`test:ui` 已内置先 `npm run build`**。
- `dist:verify` 会先完整打包（较慢），自动找到最近产出的 `release*/win-unpacked/`，先比对包内容是否与当前源码一致，再让解包 exe 追加 `--smoke-test` 自跑自检。
- **为什么要 `check:parity`**：曾经有过"exe 落后源码 6 个提交而无人察觉"的情况——代码改了一堆，发到手上的包还是旧的。这个校验解开 `app.asar`，把包内 `dist/**`、`server.js`、`electron/main.cjs` 与当前源码逐文件比 sha1，`package.json` 只比对 `version` 与运行时依赖（其余字段会被 electron-builder 正常裁剪）。比对前会做行尾规范化，所以本机 `core.autocrlf=true` 造成的 CRLF/LF 差异不会误报。
- API / UI 冒烟每次都把数据写到系统临时目录、跑完即删，绝不碰 `data/` 真实数据。
- AI 冒烟用本地假上游（OpenAI / Ollama 原生 / Anthropic 三种协议），不联网、不耗 token，因此能稳定断言：Ollama 的 `think:false` 是否还在（关掉它会让 qwen3 慢 ~30 倍）、`\r` 分帧能否解析、Anthropic 事件流是否转成 OpenAI 形状、缓存命中 token 是否合成、上游 500/掉线时是否优雅降级。

## 技术说明

- **编辑器内核**：[CodeMirror 6](https://codemirror.net/)——与 Obsidian 客户端同款的编辑器引擎，中文输入法兼容性与撤销历史均有成熟保障。
- **AI 接口**：OpenAI 兼容协议（`/chat/completions`，SSE 流式），DeepSeek / 智谱 / Kimi / OpenAI 及本地 Ollama 等均可直接使用。
- **本地服务**：`server.js` 仅用 Node 内置模块（零运行时依赖），负责静态页面、JSON 数据存取与 AI 转发。入站数据的校验/裁剪与快照表换算放在 `server-lib/schema.js`（纯函数、无 IO、无进程状态），带磁盘与内存缓存的部分留在 `server.js`。打包清单里必须带上 `server-lib/**` 与 `electron/**`，`npm run check:parity` 按目录枚举逐个比对包内与源码（新增文件自动纳入，现 22 项）——漏打包的表现为「启动即 500」或「标题栏颜色不跟主题」，靠这条守住。
- **单文件长到没人敢改就按域拆**：样式从 `index.css`（5397 行）拆到 `src/styles/*.css` 十个分区文件，`index.css` 只留按序 `@import`（Vite 合成一个产物，实测 CSS 哈希与拆分前逐字节相同，层叠顺序不变）；写作页的 AI 提示词层拆到 `src/ai-prompt.ts`（纯字符串拼装，从此可以写断言，含「章名不许混进 system 开头」这条缓存前提）；大纲页拆出 `OutlineCard.tsx`（memo 化的单张卡）与 `TimelineView.tsx`。拆完 `OutlinePanel` 1109→706 行、`WritingView` 1363→1210 行、`server.js` 1481→1241 行（后续加功能会再涨，这几个数是当下实测）。
- **拆文对标的口径**：分章、句长、对白占比、AI 味句式密度全部复用 `src/deslop.ts` 与 `src/constraints.ts` 的同一套判据（引号内不算叙述句长），所以「对标拆出来的数」和「给你自己书的达成率」是同一把尺子。`src/style.ts`（笔触漂移）走的是同一套 `bench.rhythm/compare`，只是把对照物从别人的书换成你自己的章——因此「学它」与「找回」两类卡的条件与判达成完全一致。
- **节律与利息的口径**：`src/pitch.ts` 的句子/对白/AI 味三个数直接取 `bench.chapterStats`（与拆文对标同一把尺子），琴键的高度只是拿**本书自己的中位句长**除出来的相对值——所以「这一段节奏平了」可判，「比某位作者短」不可判。台词归属只认紧贴引号前后 40 字的「名字 + 说话动词 / 冒号」，两侧都命中取更近的，认不出就留白并计入「归属不明」，宁可少说不臆造。`src/debt.ts` 的「利息」= 埋点章之后所有已写正文的章数与字数，埋点章被删算不出账就标 `unanchored`、不催账；收线卡 id 固定为 `debt-<伏笔标记 id>`，所以掉卡天然幂等。
- **桌面版标题栏怎么做的**：`titleBarStyle: 'hidden'` + `titleBarOverlay`——窗口按钮仍是原生绘制（所以 Win11 的贴边、布局推荐、双击最大化都正常），只是那条系统标题栏被藏掉，顶部 40px 交给页面当拖拽区（CSS 里 `html.desktop .view-head` 标 `drag`，它的直接子元素一律 `no-drag`，否则点不动）。颜色要跟着主题翻，所以加了 `electron/preload.cjs`：只暴露 `wb.desktop` 与 `wb.titleBarTheme(dark)` 两样，主进程收到后 `setTitleBarOverlay()` 换色。`sandbox` 与 `contextIsolation` 都保持开启，页面拿不到任何 Node 能力。浏览器模式没有这个桥，相关 CSS 挂在 `html.desktop` 下所以完全不生效。
- **提示词的块序就是 token 成本**：供应商的上下文缓存只认可**整段公共前缀**，所以 `buildAiContext` 按「多久变一次」排块——设定 / 世界观 / 战力线 / 未回收伏笔（几章才动一次）在前，按本章出场名单重排的【人物】与每章都变的前情压到最后；写作规则整段与章无关，提到身份句之后；守夜人算出的「设定红线」同样与章无关，所以排在战力记录之后、按章重排的【人物】之前——最坏情况（8 个人物都建档了境界）多花 191 字，但它整段落进命中段，批量连写只有第一章付这笔钱。实测批量连写时前缀断点从 419 字推到 566 字（同场景命中率 61%→74%，续写 63%→84%），省下来的正是那些罕变块原本每章重算的钱。这条性质由 `tests/prompt-cache.test.ts` 守着，里面带一条反面用例：真埋了新伏笔，断点就**必须**前移——不然那几条断言是恒真的。批量生成进度条上那个「缓存命中 x%（hit/total tokens）」是供应商自己回的 usage，不是估的。
- **窄窗口不挤正文、也不盖正文**：写作页一行原本要摆四块（章节栏 232 + 正文 + 工坊 330 + 抽屉 340，加间距 974 起步），1244 的窗口会把正文压成 0 宽、字数条和 AI 味提示全竖着排。现在 `<1440` 时工坊退成右侧一条 46px **图标竖栏**（一格一个动作的首字：续/润/扩/起/生/联/感/视/张/风/对/任/改，点一下直接跑动作），完整面板与素材抽屉改成**浮层**，且**一次只浮一个**（开另一个会自动收这个）；浮层展开时稿纸按视口主动让宽（`max-width: max(320px, calc(100vw - 874px))`），所以谁也不遮谁——实测 1304 窗口：纯写作态正文 664px，浮层展开时稿纸 430px。浮层怎么收：工坊面板点它外面任意处 / Esc / 面板上的 ×，素材抽屉 Esc 或点那层半透明垫底。`≥1440` 一切照旧并排。章节栏 / 正文 / 竖栏**始终待在同一行**（三者都是 sticky，而包含块是整行——一旦换行，粘住的侧栏会一路滑下去压在稿纸上），所以窗口再窄也只是各自收缩、正文保底 320px，不换行。这几条都在 `test:ui:mem` 里量着：正文宽度、面板 `position`、`paper.right <= 面板.left`（不许遮字）、**滚到 700/1600px 时侧栏与稿纸的重叠面积必须为 0**、点外面与点垫底能不能收回。
- **缺失的静态资源不再回退成首页**：`/assets/*` 拿不到就老实回 404。以前未知路径一律回 `index.html`，于是「懒加载的 chunk 找不到」变成一条看不懂的 MIME 错误 + 整页白屏。
- **AI 味规则表**：句式类别参考 [oh-story-claudecode](https://github.com/zenstory-ai/oh-story-claudecode)（MIT）的 `story-deslop`，条目与判据为本项目自行整理在 `src/deslop.ts`，全部可在 `tests/deslop.test.ts` 里直接断言（含「正常中文不误报」与百万字扫描耗时上限两条硬约束）。

## 常见问题

- **窗口变窄后 AI 工坊不见了？** 宽度小于 1440 时它会收成右侧一条图标竖栏（一格一个字），点字就直接跑那个动作；竖栏最下面的箭头是「展开完整面板」。浮出来的面板不会遮字——稿纸会主动让宽，点面板外面 / Esc / 面板上的 × 就收回，素材抽屉同理（Esc 或点那层半透明垫底）。窄窗口下两个面板一次只浮一个。
- **端口被占用**：服务默认用 4321 端口，可用环境变量改：`set PORT=5000 && node server.js`。
- **提示 `node 不是内部或外部命令`**：先安装 Node.js（https://nodejs.org ），安装后重新打开 bat。
- **启动就退出并提示 Node 版本**：服务端需要 Node.js 18 或更新（用到 `Object.hasOwn`、`structuredClone` 等），旧版本只会抛一句看不懂的 SyntaxError，所以改成开门见山告诉你（`package.json` 里也写了 `engines`）。
- **AI 调用报错**：先在「设置」页点「保存并测试连接」看具体报错；常见原因是 Key 错误、额度用尽或模型名写错。
- **侧栏一直显示「保存失败·重试」**：把鼠标停在状态点上，提示里会写明服务端给的原因。最常见的是整包体积超过 `WB_MAX_BODY_MB`（默认 96MB）上限——先删掉不要的作品/作品里的历史版本，或按上面的方式放宽上限；数据本身不会被覆盖。
